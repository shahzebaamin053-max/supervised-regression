# Supervised Regression - Dimensionality Reduction (PCA)

This project demonstrates Dimensionality Reduction using Principal Component Analysis (PCA) on a real dataset.

### Tools Used:
- Python, Google Colab
- Pandas, NumPy, Matplotlib, Seaborn
- Scikit-learn

### What I Did:
1. Explored and cleaned the dataset
2. Standardized the data for PCA
3. Applied PCA to reduce dimensions from N to 2D
4. Visualized variance and 2D projection
5. Analyzed explained variance ratio

### Key Concepts:
- Curse of Dimensionality
- Feature Scaling
- PCA, Explained Variance
- Data Visualization

### How to Run:
Open the .ipynb file in Google Colab and run all cells.
